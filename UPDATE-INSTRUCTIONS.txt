IslandX v1.2.3 media visibility fix

Changed files:
- app/build.gradle.kts
- app/src/main/java/com/islandx/app/service/IslandNotificationListener.kt
- CHANGELOG.md
- UPDATE-INSTRUCTIONS.txt

Fixes:
- Music icon/visualizer can appear even when the media app has not provided metadata yet.
- Session selection prefers a playing or paused session over an unrelated/stale session.
- Buffering and connecting sessions are treated as active so the capsule can remain visible.

Important:
- Enable Android Settings > Apps > Special app access > Notification access > IslandX.
- In IslandX settings, keep Music enabled.
- Run GitHub Actions > Build APK and wait for it to succeed before installing the APK.
- This patch has not been built or tested on a physical device in this environment.
