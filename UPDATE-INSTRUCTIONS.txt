IslandX v1.2.3 — cutout position patch

Changed files:
1. app/src/main/java/com/islandx/app/service/IslandOverlayService.kt
2. app/src/main/java/com/islandx/app/data/SettingsRepository.kt
3. app/build.gradle.kts
4. CHANGELOG.md
5. UPDATE-INSTRUCTIONS.txt

What changed:
- Removed the extra 6dp offset that was always added to the overlay's vertical position.
- Changed the default vertical offset from 6dp to 0dp.
- Kept current tap and gesture code unchanged.

How to use:
1. Back up your existing IslandX project folder.
2. Copy these updated files into the same paths in your local project, replacing the old files.
3. Commit the changed files to GitHub.
4. Run the Build APK workflow.
5. Test with IslandX's vertical offset set to 0 in its settings.

Important:
This patch does not add AccessibilityService. A normal application overlay cannot reliably cover Android status-bar icons. To test a TYPE_ACCESSIBILITY_OVERLAY approach, a real AccessibilityService must be implemented and enabled by the user. This patch is only the safer positioning fix and has not been built/tested on a physical device.
