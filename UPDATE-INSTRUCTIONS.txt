IslandX v1.2.4 — Accessibility Overlay test patch

Changed files:
1. app/src/main/AndroidManifest.xml
2. app/src/main/java/com/islandx/app/service/IslandAccessibilityService.kt (new)
3. app/src/main/java/com/islandx/app/service/IslandOverlayService.kt
4. app/src/main/java/com/islandx/app/ui/HomeScreen.kt
5. app/src/main/res/xml/island_accessibility_service.xml (new)
6. app/src/main/res/values/strings.xml
7. app/build.gradle.kts
8. CHANGELOG.md
9. README.md

What changed:
- Added a real AccessibilityService using TYPE_ACCESSIBILITY_OVERLAY.
- Added an Accessibility Overlay permission row that opens Android Accessibility Settings.
- Reuses the existing Compose IslandOverlay UI, so music, gestures, and cards are not replaced with a separate XML island.
- Avoids intentionally showing both the regular and accessibility overlay at the same time.
- The existing Display over other apps permission remains as a fallback.
- Version updated to 1.2.4 / versionCode 6.

How to apply using GitHub:
1. Back up your current project first.
2. Copy each changed/new file listed above to the same path in your repository.
3. Commit/push the changes to GitHub.
4. Open Actions > Build APK and wait for the workflow to finish.
5. Download the IslandX-debug-apk artifact only if the workflow succeeds.
6. Install it, open IslandX, and enable Display over other apps and Notification access as before.
7. In IslandX Setup, tap Accessibility overlay and enable "IslandX Overlay" in Android Settings.
8. Return to IslandX and test the capsule, music controls, gestures, notifications, and status-bar overlap.

Important:
- The accessibility permission is optional but powerful. The service declares canRetrieveWindowContent=false and does not read screen content.
- Android/device software controls system-window layering. This patch is a test implementation and cannot guarantee that every status-bar icon or heads-up notification will be behind the island.
- This environment did not have Gradle or a Gradle wrapper available, so a full Android build has NOT been run here. Do not assume the APK compiles until GitHub Actions succeeds.
